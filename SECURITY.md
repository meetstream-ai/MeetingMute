# Security

MeetingMute asks for one permission, Accessibility, and uses it only to read popups from apps you muted and to press their decline or close buttons. It has no network code.

If you find a way MeetingMute could act on the wrong window, leak data, or be abused by another app, please report it privately through [GitHub's private vulnerability reporting](https://github.com/meetstream-ai/MeetingMute/security/advisories/new) instead of a public issue. We aim to reply within a few days.
